# 🚗 DriveBee

DriveBee is a trusted vehicle rental marketplace for Sri Lanka.

## Vision

To make renting vehicles in Sri Lanka simple, safe, and trustworthy for both customers and vehicle owners.

## Phase 1

- Car Rental
- Motorcycle Rental
- With Driver
- Without Driver
- Online Booking
- Online Deposit Payment
- Owner Registration
- Admin Approval System

## Future Roadmap

- Wedding Cars
- Wedding Decorations
- Airport Transfers
- Tourism Packages
- Driver Marketplace
- Mobile Wallet
- AI Vehicle Recommendations

## Technology Stack

### Mobile

### Backend
